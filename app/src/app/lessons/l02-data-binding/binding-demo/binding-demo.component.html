Lesson 2: Data Binding

1. Interpolation — {{ '{{ expression }}' }}

Renders a TypeScript expression as text inside the template.

Hello, {{ username }}! You've clicked {{ clickCount }} times.

2. Property binding — [property]="expression"

Sets a DOM property (or an @Input) from a TypeScript expression.

This div's background color is bound to boxColor.

This paragraph gets the .important class conditionally via [class.important].

3. Event binding — (event)="handler()"

Runs a method when a DOM event fires.

4. Two-way binding — [(ngModel)]="property"

Shorthand for binding a property AND listening for its change event at the same time — keeps a form control and a class property in sync in both directions. Requires importing FormsModule (see the component's imports array).
