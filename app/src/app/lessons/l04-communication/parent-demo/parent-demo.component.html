Lesson 4: Component Communication

Parent → child: @Input

The parent passes a starting value and a label down to each child.

Child → parent: @Output

Counter A emits its new value on every click; the parent is listening.

Last value from Counter A: {{ lastValueFromA }} (changed {{ totalClicks }} times)

Direct access: @ViewChild

The parent can also reach into a specific child instance by template reference.
