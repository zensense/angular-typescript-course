Lesson 6: Routing

This whole feature (l06-routing/*) is lazy-loaded — Angular only fetches this code when you navigate here. Inside it there's a nested route with a route parameter and a "leave without saving?" guard.

View products →

What to notice in the code

  • app.routes.ts uses loadChildren to lazy-load l06-routing.routes.ts.
  • product-list links to product-detail using a route parameter: /l06-routing/products/2.
  • product-detail reads that parameter via ActivatedRoute.
  • Editing the description field, then trying to navigate away, triggers canLeaveGuard.
