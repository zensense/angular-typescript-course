Structural directives: two syntaxes, same job

Angular 17+ has built-in control-flow syntax (@if/@for). Most existing Angular code — and anything you'll find in older tutorials or jobs still on Angular <17 — uses the structural directives *ngIf/*ngFor instead. They do the same thing; both are shown here.

Modern (@if):

@if (showDetails) {

These details are visible because showDetails is true.
